# MyAiku Bot

MyAiku adalah Telegram Personal Assistant yang berjalan 24/7 di Home Server.

## ✨ Fitur (Roadmap)

- Productivity
  - Todo
  - Reminder
  - Notes
  - Deadline

- Finance
  - Income
  - Expense
  - Statistics

- Utilities
  - Password Generator
  - QR Generator
  - Hash
  - Converter

- Information
  - Weather
  - Currency
  - News
  - Calendar

- File Tools
  - PDF
  - OCR
  - ZIP
  - Image Tools

## 🛠 Tech Stack

- Python 3
- python-telegram-bot
- PostgreSQL
- Redis
- Docker
- Grafana
- Prometheus
